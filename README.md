# Momentum — Habit Tracker Prototype

A full interactive UI/UX prototype for a habit-tracking mobile app, built with vanilla HTML, CSS, and JavaScript — no frameworks.

## Features
- Onboarding flow (3-step intro)
- Home dashboard with a live progress ring and category filters
- Full habit CRUD: add, edit, delete, and view detailed history per habit
- Weekly bar chart, monthly heatmap, and a 6-badge achievement system
- Working dark mode toggle that re-themes the entire app
- Toast notifications and a completion celebration animation

## Tech
HTML5 · CSS3 (custom properties) · Vanilla JavaScript (single shared state model)
